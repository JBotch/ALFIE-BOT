# ALFIE-BOT

AlfieBot is a small desktop companion robot, designed to be 3D printed on a
Bambu Lab A1 Mini.

- [`AlfieBot_Fusion_Generator/`](AlfieBot_Fusion_Generator/README.md): Autodesk Fusion Python script that generates the parametric V0.1 CAD assembly, with its docs
- [`reference/alfiebot_concept.png`](reference/alfiebot_concept.png): original concept image
